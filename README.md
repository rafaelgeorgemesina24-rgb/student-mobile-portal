# Student Mobile Portal

This project is a Git and GitHub practice project for the Student Mobile Portal.

## Student Profile Component

The `StudentProfile.jsx` component displays basic student information:

- Name
- Student ID
- Program

The component uses fictional student data and follows meaningful naming and consistent formatting.

## Integration Example

The `StudentProfile` component can be imported into a React application using:

```jsx
import StudentProfile from "./StudentProfile";

function App() {
  return <StudentProfile />;
}
